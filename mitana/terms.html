利用規約

制定日：2026年11月23日

この利用規約（以下「本規約」）は、「ミタヨ」（以下「本アプリ」）を使うときの決まりです。本アプリを使った時点で、本規約に同意したものとします。

1. 本アプリの内容

本アプリは、見た映画・ドラマ・アニメを記録し、自分のランキングを作り、使っているサブスクの1時間あたりの料金などを確かめるためのアプリです。完全無料で、広告や課金はありません。

2. 作品の情報について

  • 作品の情報（題名・あらすじ・出演者・ポスター・公開日など）は TMDB のデータです。本アプリは TMDB と TMDB の API を使っていますが、TMDB が認めた・保証したものではありません。
  • 配信の情報（どのサブスクで見られるか）は JustWatch のデータです。配信の状況は変わります。実際に見られるかは、各サービスで確かめてください。
  • Netflix 日本のトップ10 は、Netflix が公開している「Netflix Top 10」のデータです。本アプリは Netflix が認めた・提携しているものではありません。
  • 日本での注目度はウィキペディアの閲覧数をもとにしています。あらすじの一部はウィキペディア（CC BY-SA 4.0）から引いています。
  • 公開日・放送日・配信の情報・サブスクの料金などは、実際と違うことがあります。運営者は、情報の正しさや新しさを保証しません。

3. 禁止事項

利用者は、次のことをしてはいけません。

  • 法令や公序良俗に反すること
  • ほかの人の権利（著作権・プライバシーなど）を侵害すること
  • 本アプリや、本アプリが使う外部のサービスに、過度な負荷をかけること
  • 本アプリを解析・改変して、本規約に反する目的で使うこと

4. データの保管

記録したデータは、利用者の iPhone の中と、利用者自身の iCloud に保存されます。運営者は利用者のデータを預かっていないため、データの消失について責任を負いません。大切な記録は、設定の「書き出す」で予備を作ってください。

運営者は、本アプリを使ったこと、または使えなかったことで利用者に生じた損害について、運営者の故意または重い過失による場合を除き、責任を負いません。本アプリの内容は、予告なく変えたり、提供をやめたりすることがあります。

6. 本規約の変更

本規約を変えるときは、このページでお知らせします。変えたあとに本アプリを使った時点で、変えた規約に同意したものとします。
