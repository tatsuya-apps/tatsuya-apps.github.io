ミタヨ

見た映画・ドラマ・アニメを記録して、自分だけのランキングを作り、使っているサブスクの元が取れているかがわかる iPhone のアプリです。完全無料・広告なし・アカウントなし。

主な機能
  • 見た作品・見ている作品・気になる作品の記録（Netflix の視聴履歴の読み込みにも対応）
  • 「どっちが好き？」で作る映画・ドラマ・アニメのランキング
  • サブスクの1時間あたりの料金
  • 映画館の上映中・公開予定と、公開日の知らせ
  • 友達におすすめを送る（画像とリンク）

データの出典

作品の情報：TMDB（このアプリは TMDB と TMDB の API を使っていますが、TMDB が認めた・保証したものではありません）。配信の情報：JustWatch。トップ10：Netflix Top 10。日本での注目度：ウィキメディアの閲覧数。あらすじの一部：ウィキペディア（CC BY-SA 4.0）。
