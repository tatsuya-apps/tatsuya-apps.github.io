プライバシーポリシー

制定日：2026年11月23日／改定日：2026年11月24日（「みんなのランキング」を加えました）

「ミタヨ」（以下「本アプリ」）は、利用者の情報を次のとおり取り扱います。

1. 運営者

運営者：Tatsuya Suzuki
お問い合わせ：tatsuya.apps@icloud.com

2. 運営者が集める情報

本アプリには、アカウントの登録はありません。運営者のサーバーもありません。利用者が記録したメモ・見た日・払った金額・サブスクの料金などは集めません。

ただし、「みんなのランキング」に参加している場合は、作品ごとの記録の一部を、だれの記録か分からない形で集めます（下の 3.）。

利用状況の分析ツールや広告は使っていません。ほかのアプリや Web サイトをまたいで利用者を追跡することもありません。

3. みんなのランキング

ミタヨを使う人みんなの記録から、「今みんなが見ている作品」「みんなのベスト」などのランキングを作るため、参加している利用者から次の情報を集めます。

送るもの送らないもの
・作品の番号（TMDB の番号）と種類（映画・ドラマ・アニメ）
・状態（見た・途中・気になる・やめた）
・作品の★
・いつ見たか（週まで。例：2026年の第48週）
・見たサブスク・場所（利用者が選んだもの、または Netflix の視聴履歴から読み込んだものだけ）
・「どっちが好き？」で比べた結果（どちらの作品を選んだか・同じくらいか・週）
・国（App Store の国） 		・名前・メールアドレス・Apple ID
・メモ・ひとこと・タグ
・見た日そのもの（週より細かい日付）
・払った金額・サブスクの料金
・端末の位置・連絡先・写真
  • 置き場所：Apple の CloudKit の公開の場所（本アプリ用。運営者のサーバーではありません）。
  • だれの記録か分からない形：1つの記録には、Apple がアプリごとに作る番号と作品の番号から作った、元に戻せない符号を名前として付けます。同じ人の同じ作品は1件になり、上書きされます。また CloudKit の仕組みで、記録には Apple がアプリごとに作る番号（名前やメールアドレスは含まれない番号）が付きます。運営者は、これらから利用者の名前・Apple ID・メールアドレスを知ることはできず、集計にも使いません。
  • 使い方：作品ごと・国ごと・週ごとに人数や★を数え、ランキングとして本アプリの中に出します。少ない人数（5人未満）の作品は出しません。個人の記録をそのまま出すことはありません。
  • 送るとき：アプリを開いたときと閉じたときに、変わった分だけ送ります（6時間に1回まで）。iCloud にログインしていない iPhone からは送りません。
  • 参加をやめる：本アプリの設定「みんなのランキングに参加する」をオフにすると、送らなくなり、それまでに送った分も消えます。初めて開いたときにも、参加するかどうかを選べます。アプリを消しただけでは送った分は消えないので、消したいときは先に設定でオフにしてください。

4. iPhone と利用者の iCloud に保存する情報

次の情報は、利用者の iPhone の中と、利用者自身の iCloud（Apple の CloudKit の非公開の場所）に保存します。

  • 作品（題名・種類・状態・★・メモ・どこまで見たか・タグ・ランキングの順番）と、作品の情報（あらすじ・出演者・ポスターの場所など。下の 6. のサービスから取ったもの）
  • 見た記録（見た日・見た場所（サブスク・無料配信・映画館など）・映画館の名前とスクリーン・払った金額・★・ひとこと・見た時間）、話ごとの記録
  • 「どっちが好き？」で比べた結果
  • サブスク（サービスの名前・月額・プラン・契約を始めた日・請求日・無料体験の終わる日）

iCloud に保存した情報は、同じ Apple ID でログインした利用者の端末どうしで自動で同期されます。運営者は、利用者の iCloud の中の情報を見ることはできません。保存と扱いは Apple のプライバシーポリシーによります。iPhone で iCloud にログインしていない場合などは、iPhone の中だけに保存します。

次の情報は、iPhone の中だけに保存します：画面の設定、知らせの設定、作品の情報を取った日、読み込んだ Netflix の視聴履歴の行の印（題名と日付から作った、元に戻せない短い符号）、表示を速くするための一時的なデータ。

5. Netflix の視聴履歴の読み込み

利用者が Netflix の Web サイトからダウンロードした視聴履歴のファイルを読み込む機能があります。ファイルは iPhone の中で読み、運営者を含めて、どこにもそのまま送ることはありません。

ただし、読み込んだ作品を作品の情報と結び付けるため、作品の題名を TMDB の検索に送ります（下の 6.）。日付や視聴の順番など、題名のほかの情報は送りません。

6. 外部のサービスへの問い合わせ

本アプリは、作品の情報などを表示するために、次のサービスに問い合わせます。送るのは、作品の番号・題名・調べる言葉など、問い合わせに必要なものだけです。利用者の名前や連絡先、記録の中身は送りません。問い合わせの際、各サービスには通常のインターネットの通信と同じく、利用者の IP アドレスなどが伝わります。

サービス使い方送るもの
TMDB（The Movie Database）作品の情報・ポスター・出演者・配信先（配信の情報は JustWatch のデータ）・映画館の上映作品作品の番号、探す言葉・題名、国と言語
ウィキメディア（ウィキペディア・Wikidata）日本での注目度（ウィキペディアの閲覧数）、あらすじの補い、キーワードで探す作品の番号、ページの名前、探す言葉
YouTube予告編の再生（アプリの中で YouTube の埋め込みの再生を使う）動画の番号。再生中の扱いは Google のプライバシーポリシーによります
GitHub Pages（tatsuya-apps.github.io）毎日作り直す注目度と Netflix トップ10 のデータを読むなし（ファイルを読むだけ）

「上映館・時間を探す」を押すと Google の検索を、出典のリンクを押すと各サービスのページを、Safari などで開きます。開いたあとの情報は、それぞれのサービスのプライバシーポリシーによって扱われます。

7. 知らせ

「気になる」にした映画の公開日や、作品がサブスクで見られるようになったことを知らせる機能は、iPhone の中だけで知らせを出します（運営者のサーバーから送るものではありません）。知らせを出すには、利用者の許可が必要です。iPhone の設定でいつでも止められます。

8. 友達にすすめる

「友達にすすめる」で作る画像や文は、利用者が選んだアプリ（LINE など）で、利用者が選んだ相手に送られます。画像と一緒に送るリンクは、作品の番号と題名を含むページ（tatsuya-apps.github.io/mitana/w/）のリンクです。作品の情報はリンクの「#」より後ろにあり、ページを開いてもサーバーには送られません。

9. このポリシーの変更

このポリシーを変えるときは、このページでお知らせします。
